# Jewellery-PayRoll

A Payroll & HR Management application built for **SAI Jewellers** — a jewellery retail shop.

## Features

- 👥 Employee Management (Staff, Goldsmiths, Sales Team)
- 🕐 Attendance & Time Tracking with biometric source log
- 💰 Payroll Processing with salary breakup (Basic / HRA / PF / ESI / TDS)
- 🎁 Incentives & Sales Commission tracking per employee
- 📊 Reports & Analytics dashboard

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- [Next.js 16](https://nextjs.org) — React framework
- TypeScript
- Recharts — data visualization
- Lucide React — icons
